## SDLC standards

The canonical SDLC root is exactly `~/.agents/sdlc`. Never search the
filesystem to locate it. If `~/.agents/sdlc/MAIN.md` is absent or unreadable,
report that exact path.

Read `~/.agents/sdlc/MAIN.md` in full. Preserve Spec Kit's tasks as the source
of truth. Every task or issue identifier presented to a human must include its
adjacent short descriptor.
