## Problem

Users need to visually compare original and upscaled versions to judge quality and decide whether the chosen model suits their content.

## Solution

1. Implement a comparison view with a draggable vertical slider divider
2. Left side shows original image, right side shows upscaled image
3. Both sides zoom and pan in sync so the same region is always visible
4. Toggle between comparison mode and full upscaled view
