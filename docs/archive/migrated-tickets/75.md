## Problem

Superscale UX v2 needs a Generate workspace that presents prompt packs, prompt entry, model selection, reference images, cost status, generation progress, downloaded output, and one-action handoff to local upscaling. This is the first integrated user-visible loop for the v2 product.

`RT-75.1` through `RT-75.7` are regression tests because Generate mode controls, state transitions, output actions, and handoff are permanent v2 behaviours.

`UT-75.1` is a user test because visual and workflow fit require human judgement.

## Solution Design

### Scope

- Build the Generate mode from `docs/v2/WIREFRAMES.md`.
- Use `xai/grok-imagine-image` as the default MVP model.
- Integrate prompt-pack selection, prompt entry, reference wells, and generation state.
- Wire real generation through `FalGenerationKit` only after fixture-backed coordinator tests exist.
- Wire generated output into the shared upscale coordinator.

### Patterns to follow

- Keep views declarative and state-driven.
- Keep generation orchestration in `SuperscaleUXCore`.
- Keep network calls behind injectable services so tests can use fixtures.
- Treat visual polish as discovery follow-up unless it blocks usability.

### Anti-patterns to avoid

- Do not call paid FAL endpoints from automated tests.
- Do not hide generation work inside SwiftUI `body`.
- Do not duplicate local upscale pipeline logic.
- Do not add non-MVP Google or Replicate UI.
- Avoid CODING.md violations: hidden errors, hard-coded structured data, and tests that verify source strings instead of behaviour.
- Avoid CODE/SWIFT.md violations: unstructured background UI updates, `Task.detached` without justification, force unwraps, and `try!`.

### Test locations

- `Tests/SuperscaleUXCoreTests/` for coordinator state tests.
- GUI/app test target for Generate mode control and output-state tests.
- Existing or new fixture resources for generated images and provider responses.

## Dependencies

- Depends on v2 foundation, upscale handoff, FAL core, settings/secrets, and prompt-pack loading.
