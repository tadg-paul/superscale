## Original issue body

## Problem

Superscale runs only on macOS. Bringing it to iPhone and iPad would let users upscale images on mobile devices, which also have Neural Engine hardware.

## Solution

1. Adapt SuperscaleKit for iOS (CoreML works on iOS; image I/O uses UIImage/Photos framework instead of NSImage/AppKit)
2. iOS SwiftUI interface — photo picker, share sheet integration
3. Memory management for large images on devices with less RAM (iPhone typically 6–8 GB vs Mac 16–24 GB)
4. Tile size tuning for iOS Neural Engine (different performance profile than Mac)
5. Photos extension (upscale from within the Photos app)
6. iPad-specific layout

### Risk

iPhone RAM constraints are the primary concern. A 1024×1024 → 4096×4096 upscale at 4× produces a ~64 MB output buffer. Tile-based processing helps but needs careful memory management. Older devices (A-series chips) may be too slow for practical use.
