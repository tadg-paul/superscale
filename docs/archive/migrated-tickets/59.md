## Original issue body

## Problem

The CLI help text has two sections for models: MODELS (a summary table) followed by MODEL DETAILS (a paragraph per model). This reads as repetition and makes the help text longer than necessary.

## Solution

Merge the two sections into a single MODELS section. Each model entry shows the CLI name, scale, one-line summary, and the detailed description as an indented paragraph beneath it. Remove the separate MODEL DETAILS heading.

The merged format:

\`\`\`
MODELS
    realesrgan-x4plus         4×    General photographs (default)
        Best for general photographs. Balanced sharpening and detail
        preservation. RRDBNet architecture.

    realesrgan-x2plus         2×    General photographs
        Preserves more original detail with less hallucination than
        4× models. Use for a lighter upscale.

    ...
\`\`\`

Now that #51 has moved descriptions into \`ModelInfo\`, the help text can optionally be generated from \`ModelRegistry\` rather than duplicated — but this is not required for this issue. A simple text merge of the existing sections is sufficient.
