## Original issue body

## Parent

Sub-issue of #14 (Phase 8: macOS SwiftUI GUI).

## Problem

The GUI only accepts images via drag-and-drop. Users expect to be able to click to open a file chooser — standard macOS behaviour.

## Solution

Add "or click here to choose a file" text below the drop target prompt. Clicking anywhere in the drop target area opens an \`NSOpenPanel\` filtered to supported image types (PNG, JPEG, TIFF, HEIC). The selected file is processed identically to a dropped file.
