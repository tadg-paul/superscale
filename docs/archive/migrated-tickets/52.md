## Original issue body

## Parent

Sub-issue of #14 (Phase 8: macOS SwiftUI GUI).

## Problem

The CLI provides \`--download-face-model\` with an interactive licence acceptance prompt. The GUI has no equivalent. Users need a way to download and install the GFPGAN face model from within the GUI, with proper licence review and acceptance.

## Solution

### Single face icon, two behaviours

The model selection sheet always shows a face enhancement icon (e.g. a face glyph) with hover text explaining its purpose.

**When face model is NOT installed:**
- Icon appears in its inactive/outline state
- Clicking the icon triggers the download flow:
  1. Confirmation prompt: "Face enhancement requires downloading the GFPGAN model. Download?"
  2. If user clicks Yes → present full text of BOTH licences in succession (NVIDIA Source Code Licence, then CC BY-NC-SA 4.0), each with a clickable link to the original
  3. User must click "I Agree" on each licence separately
  4. Download with progress indicator
  5. On success: icon switches to active/filled state, face enhancement is enabled

**When face model IS installed:**
- Icon acts as a simple toggle (click to enable/disable face enhancement)
- Filled when enabled, outline when disabled
- Defaults to enabled

**Hover text** (always visible on hover): brief description of what face enhancement does.

No separate ⓘ button — the hover text on the icon itself provides the information.

### Face enhancement toggle on loaded images

When a photo is loaded and the user toggles face enhancement on or off, the app switches between cached versions instantly — no re-processing.

**Implementation:** `Pipeline.process()` is extended to expose the pre-face-enhance intermediate image (the output after tiling/stitching but before `FaceEnhancer` runs). A single pipeline run with face enhancement enabled produces both versions:

1. The pre-face-enhance image (cached as `resultWithoutFaces`)
2. The final face-enhanced image (cached as `resultWithFaces`)

The GUI's `result` property returns whichever version matches the current `faceEnhance` toggle. Toggling swaps instantly between the two cached images.

The cache is invalidated when the model, scale, or input image changes — in those cases a full pipeline re-run is needed.

**SuperscaleKit change required:** Add an optional `onPreFaceEnhance: ((CGImage) -> Void)?` callback to `Pipeline.process()`, called with the stitched image just before face enhancement runs. This is a non-breaking addition (default nil).

### Licence text integrity

The full licence texts are downloaded at build time (\`make fetch-licences\`) from the canonical upstream sources:
- NVIDIA: \`https://raw.githubusercontent.com/NVlabs/stylegan2/refs/heads/master/LICENSE.txt\`
- CC BY-NC-SA 4.0: \`https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.txt\`

Stored as bundle resources in \`SuperscaleApp/SuperscaleApp/Resources/\`. A regression test verifies the SHA-256 hashes of the downloaded files against known canonical values. If an upstream licence changes, the test fails, forcing a human review before the new text is accepted.

Canonical hashes:
- NVIDIA: \`803ddcc4dd20de6387e2e5731f6a864ea01364dd305b17bda7157bcab0c39295\`
- CC BY-NC-SA 4.0: \`e66c269d4819aaab34b49ef5220c4ddab6756f21bb5180761a4eb8561f2b7bbd\`
