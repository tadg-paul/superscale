## Original issue body

## Problem

The comparison view renders the original (before) image using SwiftUI's default bicubic interpolation when zoomed in. This silently applies Apple's upscaling algorithm to the original, making it appear sharper than it actually is and reducing the visible quality delta that Superscale has achieved. The user is shown an interpolated version of their original without being told.

## Solution

Add `.interpolation(.none)` to the `Image` view for the original (before) side only in `imageLayer`. The upscaled side is already processed by Superscale and can retain default rendering.

\`imageLayer\` is currently shared between both sides. It should either accept an interpolation parameter, or be split into two separate functions — one for the original with `.interpolation(.none)`, one for the upscaled with default rendering.
