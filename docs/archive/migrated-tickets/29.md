## Original issue body

## Problem

`--download-face-model` currently supports a `--accept-licence` flag for non-interactive use. This undermines the licence notice — users can skip reading the non-commercial terms by scripting the flag. The licence acceptance should be a deliberate, interactive act.

## Solution

1. **TTY mode**: Print the full licence notice on screen, prompt `Do you accept these terms? [y/N]`, wait for confirmation before downloading
2. **Non-TTY mode**: Fail immediately with a stderr message: `"Error: --download-face-model requires an interactive terminal. Run this command in a terminal to view and accept the licence terms."`
3. **Remove `--accept-licence`**: Delete the flag entirely — there is no non-interactive path

### Behaviour

```bash
# In a terminal — works, shows licence, waits for y/N
superscale --download-face-model

# Piped or scripted — fails with clear message
echo | superscale --download-face-model  # fails
superscale --download-face-model < /dev/null  # fails
```
