## Original issue body

## Problem

The upscaling pipeline needs to read input images in common formats and write output images preserving colour profiles and handling alpha channels.

## Solution

Implement two components in `Sources/Superscale/Pipeline/`:

### ImageLoader

- Read images via `CGImageSource` (supports PNG, JPEG, TIFF, HEIC natively)
- Extract image dimensions and colour profile metadata
- Detect and separate alpha channel if present
- Return a `CGImage` (RGB) and optional alpha `CGImage` (greyscale)

### ImageWriter

- Write output as PNG (default) or JPEG via `CGImageDestination`
- Preserve the colour profile from the input image
- Recombine RGB output with upscaled alpha channel (if applicable)
- Alpha upscaling uses bicubic interpolation (fast, usually sufficient for transparency masks)
