## Problem statement

**Requested by the author, 2026-08-29:** copy twenty-two named prompts from `~/snips/prompts-genai/image/` into the built-in prompt pack.

## What is there, established

- The source directory holds **108** files; the bundled corpus holds **86**. The twenty-two named are the difference, and **none of them is already bundled** (spot-checked across three).
- Source files carry **the prompt body only**. Bundled files carry a fenced JSON header --- `id`, `name`, `category`, `requiresInput` --- followed by the same body. So this is a transformation, not a copy.
- **Two categories do not yet exist**: `Narrative` (11 of the 22) and `Institutional` (4). The existing nine are Design, Illustration, Lighting, Material, Media, Photo, Print, Sketch, Zeitgeist.

## The one judgement this needs

The filter list groups by category and is the application's primary surface --- guide 2.3 calls it *"the primary surface"*. Adding two categories changes how 86 existing filters are found, not only how 22 new ones are.

`id`, `category` and `requiresInput` all derive mechanically from the filename and the existing convention. **`name` does not**: `image-narrative-archaeological-excavation` becomes "Archaeological Excavation" by the same rule the corpus already follows, and that rule is worth stating rather than assumed, because **UT-74.1** was the author reading all 86 names and judging that they *"read as intended names rather than as filenames"*. Twenty-two more names go in front of that judgement.

## Violated or affected criteria

- **AC74.1**, that filter names read as names --- **UT-74.1** passed on the 86 and is re-offered for the 108.
- The #85 filter-catalogue family covers loading and grouping. `PromptPackCatalogue.bundled()` reads the resource directory, so nothing structural changes; the count and the categories do.
- **AC95.x** Settings shows a bundled-filter count, which moves from 86 to 108.

## Procedure

1. **Transform, do not hand-write.** Each file gets a header derived from its filename by one rule. Twenty-two hand-authored headers is twenty-two chances to differ.
2. **Bodies are copied verbatim.** They are the author's words and the thing being paid for at the provider; no reflowing, no tidying.
3. **Confirm every one of the twenty-two named is present** and that no other file is added --- the source has 108 and only 22 are wanted.
4. Check the corpus loads and the new categories appear in the filter list's grouping.
