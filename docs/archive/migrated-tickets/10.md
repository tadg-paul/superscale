## Original issue body

## Problem

The CLI scaffolding (argument parsing, --help, --version, --list-models) exists but is not wired to the actual pipeline. Batch processing (multiple input files) is not yet implemented. The CLI needs to handle all flags end-to-end.

## Solution

Wire the existing ArgumentParser scaffolding in `main.swift` to the pipeline:

1. **Batch processing**: iterate over all input file arguments, process each through the pipeline
2. **Output directory (-o)**: create if it doesn't exist, write outputs there
3. **Scale factor (-s)**: pass to pipeline, validate (must be 2 or 4)
4. **Model selection (-m)**: resolve via ModelRegistry, fail with suggestions if not found
5. **--list-models**: already scaffolded, wire to ModelRegistry for dynamic output with installed/available status
6. **Error accumulation**: if some files fail in a batch, continue processing remaining files, report all errors at the end
