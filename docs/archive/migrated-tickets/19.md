## Original issue body

## Problem

`make convert-models` fails for all 6 models with:

```
ERROR: Failed to convert realesrgan-x4plus: 'scale' must be 1.0 for a output of ImageType
```

Two root causes:
1. coremltools 7+ no longer allows `scale=255.0` on `ct.ImageType` for model outputs
2. The Makefile used `python3` which resolved to Python 3.14 — coremltools 9.0 has no native wheels for 3.14, causing `BlobWriter not loaded` errors

## Solution

1. Wrap the PyTorch model in an `OutputScaler` module that clamps output to [0, 1] and multiplies by 255, so the model itself produces [0, 255] values and we can use the required `scale=1.0` on the output `ImageType`
2. Pin the Makefile `convert-models` target to use `/opt/homebrew/bin/python3.12` explicitly
