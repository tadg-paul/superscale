## Original issue body

## Parent

Sub-issue of #14 (Phase 8: macOS SwiftUI GUI).

## Problem

The GUI currently uses a mix of tooltips, popovers, and hover text to explain controls. These are inconsistent, easy to miss, and don't provide contextual guidance during the upscaling workflow.

## Solution

A translucent contextual info panel positioned at the top of the content area, below the toolbar. Uses `.ultraThinMaterial` background with ~80% opacity. Content changes dynamically based on current state.

### Content (contextual, built from current state)

- **Model:** "General photo 4× (realesrgan-x4plus)" — always shown
- **Scale:** "Upscaling to 4×" or "Custom resolution: enter width or height" — when custom fields are focused, includes the explanation about native scale + interpolation for >4× targets
- **Stretch:** "Stretch enabled — output will match exact dimensions, ignoring aspect ratio" — only when stretch is on
- **Face enhancement:** "Face enhancement enabled (GFPGAN, non-commercial licence)" — when enabled
- **Post-upscale summary:** "Upscaled 512×512 → 2048×2048 using realesrgan-x4plus" — after processing

### Behaviour

- Dismissable with × button (useful when viewing result image)
- Auto-hides in Compare mode
- Reappears when settings change (model, scale, etc.)
- Positioned near the top, visually close to the toolbar controls

### Replaces

- Custom resolution hover tooltip on ruler button
- Stretch hover tooltip

Model selector sheet keeps its own ⓘ (separate context).
