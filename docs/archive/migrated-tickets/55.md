## Problem

The GUI app is currently ad-hoc signed. macOS Gatekeeper blocks it on first launch, requiring users to bypass via right-click → Open or \`xattr -cr\`. This is a poor first-run experience.

## Solution

Sign the \`.app\` bundle with a Developer ID certificate and submit it to Apple's notary service before packaging the DMG. This allows Gatekeeper to verify the app without user intervention.

### Steps

1. Sign with \`codesign --force --deep --sign "Developer ID Application: [name]"\` using the Developer ID certificate from the keychain
2. Submit to Apple's notary service via \`xcrun notarytool submit\`
3. Wait for notarization to complete (\`xcrun notarytool wait\`)
4. Staple the notarization ticket to the \`.app\` via \`xcrun stapler staple\`
5. Then package the DMG (after stapling)

Update \`scripts/release-gui.sh\` to replace the ad-hoc signing step with the full signing + notarization flow.

### Prerequisites

- Apple Developer Program membership (active)
- Developer ID Application certificate in the local keychain
- App-specific password or keychain profile for notarytool authentication
