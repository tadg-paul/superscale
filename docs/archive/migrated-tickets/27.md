## Problem

The README undersells the app. Key differentiators are missing or buried:

- **100% on-device** — no cloud services, no API keys, no accounts, no internet required after install
- **Privacy** — images never leave the machine
- **Neural Engine** — runs on dedicated ML hardware, not CPU/GPU (freeing those for other work)
- **Zero dependencies** — single binary, everything included
- **Speed** — inference in seconds, not minutes

The current README is functional but reads like a feature list, not a pitch.

Documentation changes — no ACs required.

## Solution

Rewrite the README with a strong opening that leads with the privacy/on-device angle, clearer USP messaging, and better-organised sections. Keep all existing technical content but present it more compellingly.
