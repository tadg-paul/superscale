## Original issue body

## Parent

Sub-issue of #14 (Phase 8: macOS SwiftUI GUI).

## Problem

Non-technical users need a visual interface for image upscaling. This sub-issue delivers the minimum viable GUI: a SwiftUI app that accepts images, upscales them, and displays the result.

## Solution

1. Add a SwiftUI app target (`SuperscaleApp`) to `Package.swift`, depending on `SuperscaleKit`
2. Main window with a prominent drag-and-drop target area
3. Model picker populated from `ModelRegistry` (all 7 models + auto-detect)
4. Scale indicator showing the selected model's native scale factor
5. Progress indicator bound to pipeline progress during processing
6. Display the upscaled result in the main window
7. File > Save / Save As to export the upscaled image

Scale/resolution picker with presets, custom resolution, and stretch mode is tracked separately in #49.
