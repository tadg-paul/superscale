## Original issue body

## Problem

The pipeline needs to load a CoreML model, run inference on image tiles, and manage a registry of supported models with their metadata.

## Solution

Implement two components in `Sources/Superscale/`:

### CoreMLInference (`Pipeline/CoreMLInference.swift`)

- Load a `.mlpackage` model via `MLModel(contentsOf:)`
- Accept a `CGImage` tile, convert to `MLMultiArray` or `CVPixelBuffer` input
- Run prediction and extract the output image
- Return the upscaled tile as a `CGImage`
- CoreML automatically dispatches to Neural Engine, GPU, or CPU

### ModelRegistry (`Models/ModelRegistry.swift`)

- Static catalogue of supported models with metadata:
  - CLI name (e.g. `realesrgan-x4plus`)
  - Display name (e.g. "General Photo (4×)")
  - Scale factor (2 or 4)
  - Recommended tile size
  - Filename (e.g. `RealESRGAN_x4plus.mlpackage`)
- Model resolution: given a CLI name, find the `.mlpackage` file
  - Check bundled location first (relative to binary or Cellar)
  - Check user model directory (`~/Library/Application Support/superscale/models/`)
  - Return path or error with instructions
