## Original issue body

## Problem

`scripts/release-gui.sh` sets `APP_NAME="Superscale"` and passes it to `xcodebuild -scheme "${APP_NAME}"`. The actual shared scheme for building the app is `SuperscaleWithTests`; the scheme named `Superscale` (capital S) does not exist, causing the release to fail immediately at the build step.

The scheme was added as `SuperscaleWithTests` when XCUITest infrastructure was introduced in #57. Before that, an implicit `Superscale` scheme may have been resolved by Xcode, but it is no longer reliably available.

## Solution

In `release-gui.sh`, separate the scheme identifier from the app bundle name:

```bash
SCHEME="SuperscaleWithTests"
APP_NAME="Superscale"
```

Replace the two `xcodebuild` invocations (showBuildSettings and build) to use `-scheme "${SCHEME}"` instead of `-scheme "${APP_NAME}"`. The rest of the script (app path, DMG name, cask) continues to use `${APP_NAME}`.
