## Original issue body

## Problem

After upscaling completes the user has to manually enter comparison mode to see the before/after delta — the most compelling part of the experience. Additionally, when zoomed in there is no spatial reference showing where in the image you are.

## Solution

### Auto-enter comparison on completion

When upscaling completes, automatically switch to comparison view. No manual step required. The result image is still accessible (the comparison view shows it on the right side).

Trigger: set a flag/state in `UpscaleViewModel` after processing completes that causes `MainView` to present `ComparisonView` directly.

Re-upscaling the same or a different image should also auto-enter comparison each time.

### Default divider position: 35%

Initialise `dividerPosition` to `0.35` instead of `0.5`. The "before" occupies 35% of the view — the eye moves left-to-right and hits the original briefly before landing on the larger, improved right side.

### Minimap / navigator thumbnail

When zoomed in (zoom > 1.0), show a small thumbnail of the full upscaled image in a corner (bottom-right suggested) with a semi-transparent rectangle indicating the current viewport position. Tapping/dragging the minimap pans to that position.

### Prominent zoom controls

The zoom controls (+/−/%) use SF Symbols, larger hit targets, bold monospaced percentage, and `.thickMaterial` background for easy discovery.
