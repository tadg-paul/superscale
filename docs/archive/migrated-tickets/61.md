## Original issue body

## Problem

Several UX intuitiveness issues:
- Slow typers are frustrated by the 1.5s debounce triggering upscale before they finish typing
- New users are not familiar with glyph-only buttons
- Info panel content ordering and detail could be improved
- Zoom buttons are not prominent enough

## Solution

### Text labels on buttons

Add text labels alongside glyphs for the following toolbar buttons:
- Custom (ruler icon + "Custom")
- Stretch (arrow glyph + "Stretch")
- Face Enhance (face icon + "Face Enhance")

Labels are conditional — controlled by a flag so they can later be toggled off in a settings pane (#47).

### Custom resolution entry: OK/Cancel flow

Replace the 1.5s debounce with explicit confirmation:
- When custom text fields are active, show checkmark.circle (confirm) and xmark.circle (cancel) buttons
- Upscale only triggers when ✅ is clicked (or the user clicks elsewhere, interpreted as confirm)
- ❌ reverts to the previous scale setting
- Active text fields have more prominent styling to indicate edit mode

### About box

Add a title "Models installed:" above the models list.

### Zoom buttons

Move from bottom-right to top-right of the comparison pane, closer to the toolbar.

### Info panel improvements

1. **Ordering:** Face enhancement status shown immediately after model name, not at the end
2. **Auto-detect detail:** When auto-detect selects a model, show e.g. "Anime/illustration 4× (auto-detected)" instead of just "Model: Auto-detect"
3. **Face detection detail:** After upscaling, if faces were detected and enhanced, show "2 faces enhanced (GFPGAN)" instead of just "Face enhancement enabled"
4. **Reset:** Info panel content resets when the user starts changing settings (before a new upscale completes)
5. **Remove output repetition:** Replace the current "Output: 1232×832 → 4928×3328" line (which repeats the scale line) with a separate "Input: 1232×832" line. The target dimensions are already shown on the Scale line. The format should be:
   ```
   Model: Anime/illustration (4×) (auto-detected)
   Face enhancement enabled
   Input: 1232×832
   Scale: 4× → 4928×3328
   ```

### Pipeline feedback

To support the face detection detail, `Pipeline.process()` needs to report how many faces were detected/enhanced. This can be done via the existing `onProgress` callback or a new `onResult` callback.

### Info panel font size

Increase the info panel text from `.caption` (current) to `.callout` or equivalent (+2pt). The current size is too small for comfortable reading.

### Trackpad/mouse scroll panning

Add scroll event handling to the comparison view so that trackpad two-finger scroll and mouse scroll wheel control panning, in addition to the existing click-and-drag gesture.

### Keyboard shortcuts for comparison view

Map keyboard shortcuts in the comparison view:
- `Cmd+=` and `Cmd++` → zoom in (same as clicking + button)
- `Cmd+-` → zoom out (same as clicking − button)
- Arrow keys → pan in the corresponding direction

Use SwiftUI `.onKeyPress` or `keyboardShortcut` modifiers on the comparison view.
