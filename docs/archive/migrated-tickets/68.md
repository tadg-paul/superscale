## Original issue body

## Problem

The slider comparison mode is not effective at demonstrating the upscale delta. Users must zoom in and pan to see the difference, which adds friction and doesn't immediately convey the improvement. The slider works against us — at best-fit zoom the before and after look similar.

## Solution

### Magnifier loupe mode

Add a circular magnifier ("loupe") that follows the mouse cursor over the full-size image. The loupe shows a high-magnification view split vertically down the middle:

- **Left half:** original image (nearest-neighbour interpolation) — shows actual source pixels
- **Right half:** upscaled image — shows Superscale's output
- **Centre divider:** thin vertical line through the middle of the circle

The full image remains visible at best-fit (1×) at all times. The user moves the mouse to inspect any region. The split within the loupe makes the quality delta immediately obvious at any position.

**Loupe specifications (initial):**
- Diameter: ~200px (may need tuning)
- Magnification: 4–6× of the underlying region (may need tuning)
- Follows mouse cursor position
- Visible only when the mouse is over the image area; the mouse cursor returns to its normal appearance outside the image area
- Only active in comparison mode — switching to full view (via the Compare/Full View button) hides the loupe and restores normal zoom/pan interaction

### Comparison mode toggle

Single toggle button (top-right) showing the current mode icon. Click to switch between:
- **Magnifier mode** (default) — loupe follows cursor
- **Slider mode** — existing before/after slider with divider; vertical zoom controls slide in below the toggle

Switching out of comparison mode entirely (Full View) gives the user the normal result view with zoom/pan as before — no loupe, no slider.

### Implementation approach

1. Track mouse position via `.onContinuousHover` on the magnifier content view
2. At the cursor position, crop regions from both the original and upscaled images
3. Render the loupe as a circular overlay:
   - Left semicircle clipped from original (nearest-neighbour, magnified)
   - Right semicircle clipped from upscaled (magnified)
   - Vertical divider line and circle border for definition
4. Hide the loupe and restore normal cursor when mouse exits the image area
5. Full View mode has no loupe — normal zoom/pan interaction with the upscaled result

## Solution Design

### Language, frameworks, libraries

- **Swift / SwiftUI** — all changes are in the existing Xcode GUI target
- **NSEvent** local monitor — for mouse tracking (already used in ComparisonView for scroll events)
- **CGImage / CGContext** — for sampling and rendering the magnified loupe content
- No new dependencies

### Architecture

**New file:** \`MagnifierView.swift\`
- A SwiftUI view that renders the circular loupe overlay at a given position
- Takes: mouse position, original NSImage, upscaled NSImage, view size, loupe diameter, magnification factor
- Internally renders two semicircles (left=original nearest-neighbour, right=upscaled) using \`Canvas\` or \`Image\` views clipped to semicircle shapes
- Vertical divider line through the centre
- Circle border for definition

**Modified files:**
- \`ComparisonView.swift\` — add \`comparisonMode\` enum (\`.magnifier\`, \`.slider\`), default \`.magnifier\`. When \`.magnifier\`: show full image at best-fit with MagnifierView overlay tracking mouse. When \`.slider\`: existing slider behaviour. Add mode toggle control.
- \`MainView.swift\` — no changes needed (comparison view already conditionally shown based on \`showComparison\`)
- \`UpscaleViewModel.swift\` — add \`@Published var comparisonMode: ComparisonMode = .magnifier\` to persist mode across comparison toggles

### Mouse tracking approach

Use \`NSEvent.addLocalMonitorForEvents(matching: [.mouseMoved, .mouseEntered, .mouseExited])\` — consistent with the existing scroll monitor pattern in ComparisonView. Track \`mousePosition: CGPoint?\` — nil when mouse is outside the image area (loupe hidden), non-nil when over it.

Hide the system cursor (\`NSCursor.hide()\`) when the loupe is visible and restore (\`NSCursor.unhide()\`) when it disappears, so the loupe replaces the cursor rather than overlapping it.

### Loupe rendering

For each frame (mouse move):
1. Convert mouse position to normalised image coordinates
2. Compute the source rect in both original and upscaled images (accounting for scale difference)
3. Crop and scale both regions to the loupe diameter at the target magnification
4. Original half: render with nearest-neighbour (no interpolation)
5. Upscaled half: render with default (high) interpolation
6. Clip left half to left semicircle, right half to right semicircle
7. Overlay divider line and circle border

### Patterns to use

- SwiftUI \`Canvas\` for efficient per-frame loupe rendering (avoids creating new Image views each frame)
- Enum-based mode switching (\`ComparisonMode\`) for clean state management
- Existing \`NSEvent\` monitor pattern from ComparisonView scroll handling
- \`.accessibilityIdentifier()\` on all new elements (loupe, toggle, divider) for XCUITest

### Anti-patterns to avoid

- **No string-building shell commands** (CODING.md §Prohibited Anti-Patterns) — n/a but noted
- **No error suppression** (CODING.md §Error Suppression) — CGContext creation failures must be handled, not silently ignored
- **No global state** (CODING.md §Other Prohibited Shortcuts) — mouse tracking state stays in ComparisonView, not global
- **Functions <50 lines** (CODING.md §Structure) — loupe rendering logic split into focused helpers
- **Max 3 levels nesting** (CODING.md §Structure) — keep conditional logic flat
