## Original issue body

## Problem

The GFPGAN CoreML model (`GFPGANv1.4.mlpackage.zip`) is hosted on our `models-v1` GitHub release with no licence information. Users downloading it have no visibility into the licensing terms without digging through upstream repos.

## Solution

Add a clear licence notice to the `models-v1` release description covering the face model. The notice must state:

1. These are **converted weights** — original source is [GFPGAN](https://github.com/TencentARC/GFPGAN) / [StyleGAN2](https://github.com/NVlabs/stylegan2)
2. The licence ([CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) + [NVIDIA Source Code Licence](https://github.com/NVlabs/stylegan2/blob/master/LICENSE.txt)) applies to **the weights**, not to output images
3. **Non-commercial use only**

This is a documentation-only change — no code, no tests required.
