## Original issue body

## Problem

The Real-ESRGAN `realesr-general-wdn-x4v3` model (4× upscale with built-in denoising) is not bundled or available. This model is useful for noisy source images — old scanned photos, low-light shots, heavily compressed JPEGs — where the standard models would amplify noise/grain artefacts during upscaling.

The model is BSD-3-Clause licensed (same as all other bundled models) and uses the same SRVGGNetCompact architecture as the already-bundled `realesr-general-x4v3`, so conversion and integration are straightforward.

## Solution

Convert, bundle, and document the model. Selection is manual via `-m realesr-general-wdn-x4v3` only — no auto-detection.

### Changes required

1. **`scripts/convert_model.py`** — Add wdn model to conversion list.

2. **`ModelRegistry.swift`** — Add new entry:
   ```swift
   ModelInfo(
       name: "realesr-general-wdn-x4v3",
       displayName: "General scenes with denoise (4×)",
       filename: "realesr-general-wdn-x4v3.mlpackage",
       scale: 4, tileSize: 512, isDefault: false
   )
   ```

3. **`Formula/superscale.rb`** — Add resource block (handled automatically by `make release`).

4. **README.md** — Add model to table with note that it is effective for old photos, grainy images, or heavily compressed sources.

5. **`docs/model-licensing.md`** — Change `realesr-general-wdn-x4v3` from "not currently bundled" to bundled.

### What this does NOT change

- `ContentDetector` — no auto-detection of noisy images
- Default model selection — the wdn model is manual only
