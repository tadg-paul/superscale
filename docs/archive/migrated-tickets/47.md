## Problem

Users need to configure default preferences so the app remembers their preferred model, output format, and output directory between sessions.

## Solution

1. macOS Settings window accessible via Cmd+, and the app menu
2. Default model selection (persisted via UserDefaults or equivalent)
3. Default output format (PNG, JPEG, TIFF)
4. Default output directory
5. Preferences persist across app launches
