## Original issue body

## Problem

When the info panel is dismissed via the × button, there is no way to bring it back unless a setting is changed (which triggers the \`onChange\` handlers). If the user just wants to see the info panel again without changing anything, they are stuck.

## Solution

When the info panel is dismissed, show a toolbar button (e.g. \`text.bubble\` SF Symbol) in the toolbar that restores the panel. The button disappears when the panel is visible.
