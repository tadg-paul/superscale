## Original issue body

## Parent

Sub-issue of #14 (Phase 8: macOS SwiftUI GUI).

## Problem

The GUI has no way for users to see what version of the app they are running, which models are installed, or the licence terms that apply to each model. This information is available in the CLI via \`--version\` and \`--list-models\` but has no GUI equivalent.

## Solution

An "About" button aligned to the top-right of the toolbar (ⓘ icon or similar). Clicking it opens a panel/sheet showing:

### Content

1. **App identity:** "Superscale" with app icon
2. **Version:** build version from the same source as the CLI's \`--version\` output (e.g. "v1.0.2")
3. **Author:** "By Taḋg Paul"
4. **Installed models table:** each model with CLI name, display name, scale factor, installation status, and licence (BSD-3-Clause for Real-ESRGAN; non-commercial for GFPGAN)
5. **Project link:** clickable link to the GitHub repository

### Placement

Top-right of the toolbar, after the Compare and Save As buttons. Uses an ⓘ or gear icon.
