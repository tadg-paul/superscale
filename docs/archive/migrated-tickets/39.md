## Original issue body

## Problem

The `--help` output is now a full page in a standard terminal (13 options, 1 argument, plus the usage line). It scrolls off the top of the screen, making it difficult to read. There is no pager support, no colour/formatting to aid scanning, and the content is limited to ArgumentParser's auto-generated synopsis — no examples, no model descriptions, no practical guidance.

Users currently have to visit the GitHub README or `docs/` for usage examples and model guidance. For a convenience CLI tool, the help text should serve as a self-contained usage manual.

## Solution

### 1. Custom help handler

Disable ArgumentParser's built-in help (`helpNames: []` in `CommandConfiguration`) and add a custom `--help` / `-h` flag. When set, generate a rich help document and pipe it through a pager.

### 2. Pager selection

Resolve the pager following standard shell conventions, in priority order:

1. `MANPAGER` environment variable
2. `PAGER` environment variable
3. `less` available in `PATH` (via `command -v less` equivalent)
4. Direct output to stdout (no pager)

Only invoke the pager when stdout is connected to a terminal, the session is interactive, and the process is not running in a subshell. When piped or redirected, write directly to stdout without pager.

When the resolved pager is `less`, ensure ANSI passthrough by adding `-R` to the invocation unless the `LESS` environment variable already includes it.

### 3. ANSI colour

Apply ANSI formatting following man page conventions:

| Element | Style | ANSI code |
|---------|-------|-----------|
| Section headers | Bold | `\033[1m` |
| Flag/option names | Bold | `\033[1m` |
| Argument placeholders | Underline | `\033[4m` |
| Model names (in table) | Bold | `\033[1m` |
| Dim annotations | Dim | `\033[2m` |

Colour is enabled when **all** of:
- stdout is a terminal (`isatty`)
- `NO_COLOR` environment variable is not set (respecting [no-color.org](https://no-color.org))
- `TERM` is not `dumb`

When colour is disabled (piped, redirected, `NO_COLOR`, `TERM=dumb`), output plain text with no escape sequences.

### 4. Help text structure

The help output follows this section order:

```
NAME
    superscale — AI image upscaling for Apple Silicon

USAGE
    superscale [-s <n>] [-o <dir>] [-m <name>] [--width <px>] [--height <px>]
               [--stretch] [--tile-size <px>] [--list-models] [--no-face-enhance]
               [--download-face-model] [--clear-cache] [--version] [-h]
               FILE [FILE ...]

DESCRIPTION
    Superscale upscales images using Real-ESRGAN neural networks, running
    natively on your Mac's Neural Engine via CoreML. Images never leave your
    machine. CPU and GPU stay free. A 1024×1024 image upscales 4× in seconds.

    Seven models are bundled, covering photographs, anime/illustration, and
    noisy or compressed sources. The best model is auto-selected based on
    image content using Apple's Vision framework, or you can choose one
    explicitly with -m.

ARGUMENTS
    FILE                Input image file(s). Supports PNG, JPEG, TIFF, HEIC.

OPTIONS
    -s, --scale <n>
        Scale factor. Accepts any positive number: integer (2, 4) or
        fractional (2.4, 3.5). Default: 4. Cannot be combined with
        --width/--height.

    -o, --output <dir>
        Output directory. Created if it does not exist. When omitted,
        output files are written alongside the input.

    -m, --model <name>
        Model name. See INSTALLED MODELS below for available names.
        When omitted, the model is auto-detected from image content.

    --width <px>
        Target output width in pixels. The image is upscaled at the
        model's native resolution, then resized to fit. When used alone,
        height scales proportionally to preserve aspect ratio.

    --height <px>
        Target output height in pixels. When used alone, width scales
        proportionally. When both --width and --height are given, the
        image fits within the bounding box preserving aspect ratio.

    --stretch
        Stretch to exact --width and --height, ignoring aspect ratio.
        Requires both --width and --height.

    --tile-size <px>
        Tile size in pixels for processing. Large images are split into
        overlapping tiles to fit in memory. Smaller tiles use less memory
        but require more inference passes. Default: 512. Reduce if you
        encounter memory pressure on large images.

    --list-models
        List all registered models with their installation status, then
        exit. Shows both bundled upscaling models and the optional face
        enhancement model.

    --no-face-enhance
        Skip face enhancement even when the GFPGAN model is installed.
        By default, face enhancement runs automatically on every upscale
        when the model is present.

    --download-face-model
        Download the optional GFPGAN face enhancement model. Presents
        licence terms (non-commercial) that must be accepted interactively.
        Requires a terminal — cannot be run in a script or pipe. Once
        installed, face enhancement runs automatically on every upscale.

    --clear-cache
        Clear the compiled CoreML model cache. Models are compiled from
        .mlpackage to device-optimized .mlmodelc on first use and cached
        in ~/Library/Application Support/superscale/compiled/. This flag
        forces recompilation on the next run.

    --version
        Show version information.

    -h, --help
        Show this help.

EXAMPLES
    superscale photo.png
        Upscale 4× using auto-detected model. Writes photo_4x.png.

    superscale -s 2 -o upscaled/ photo.jpg
        Upscale 2× to output directory.

    superscale -s 2.4 photo.png
        Fractional scale — produces photo_2.4x.png.

    superscale --width 4096 --height 4096 photo.png
        Fit within 4096×4096 bounding box, preserving aspect ratio.

    superscale --width 1920 --height 1080 --stretch photo.png
        Stretch to exact 1920×1080, ignoring aspect ratio.

    superscale -m realesrgan-anime-6b *.png
        Batch process with anime model.

    superscale -m realesr-general-wdn-x4v3 old_photo.jpg
        Denoise and upscale a grainy photo.

INSTALLED MODELS (details below)
    <name>                  <scale>  <description>          [installed/not installed]

    realesrgan-x4plus       4×       General photo [default]          [installed]
    realesrgan-x2plus       2×       General photo                    [installed]
    realesrnet-x4plus       4×       General photo, PSNR-oriented     [installed]
    realesrgan-anime-6b     4×       Anime/illustration               [installed]
    realesr-animevideov3    4×       Anime video frames               [installed]
    realesr-general-x4v3    4×       General scenes, compact          [installed]
    realesr-general-wdn-x4v3 4×     General scenes with denoise      [installed]

    Face enhancement:
    gfpgan-v1.4                      Face enhancement (optional)      [installed/not installed]

MODEL DETAILS
    realesrgan-x4plus (default)
        Best for general photographs. Balanced sharpening and detail
        preservation. RRDBNet architecture. The default when no model
        is specified and the image is detected as a photograph.

    realesrgan-x2plus
        General photographs at 2× scale. Preserves more original detail
        with less hallucination than 4× models. Use when you need a
        lighter upscale or want to stay closer to the source.

    realesrnet-x4plus
        PSNR-oriented variant — less aggressive sharpening, fewer
        artefacts. Preferred for images where fidelity matters more
        than perceived sharpness (e.g. medical, scientific).

    realesrgan-anime-6b
        Optimized for anime and cel-shaded illustration. Preserves
        flat colour regions and clean line art. 6-block RRDBNet.

    realesr-animevideov3
        Compact model designed for anime video frame consistency.
        SRVGGNetCompact architecture — faster inference, suitable for
        batch processing of animation frames.

    realesr-general-x4v3
        General scenes with SRVGGNetCompact — faster and lighter than
        x4plus. Good when speed matters more than maximum quality.

    realesr-general-wdn-x4v3
        Denoise variant of general-x4v3. Effective for old photographs,
        grainy scans, and heavily compressed JPEG sources. Reduces noise
        while upscaling.

FACE ENHANCEMENT
    Optional GFPGAN face enhancement. Not bundled due to non-commercial
    licence (StyleGAN2 NVIDIA Source Code Licence; DFDNet CC BY-NC-SA 4.0).
    Install with: superscale --download-face-model
    Once installed, runs automatically. Skip with --no-face-enhance.
    The licence applies to the model weights, not to output images.

REQUIREMENTS
    macOS 14 (Sonoma) or later. Apple Silicon (M1–M5+).
    No other dependencies — everything runs on built-in system frameworks.
    Intel Macs are not supported (no Neural Engine).

LICENSE

    Code Licence (non-commercial) and CC BY-NC-SA 4.0. The licence applies
    to the model weights, not to output images.

SEE ALSO
    Report bugs: https://github.com/tigger04/superscale/issues
```

### 5. Changes required

1. **`SuperscaleCommand.swift`** — set `helpNames: []` in `CommandConfiguration`, add custom `@Flag` for `-h`/`--help`, call help formatter and pager in `run()`.
2. **New `HelpFormatter.swift`** — generates the structured help text. Accepts a `useColour: Bool` parameter. Queries `ModelRegistry` for model list and `FaceModelRegistry` for face status. Model details are embedded as static content (strengths/weaknesses descriptions).
3. **New `Pager.swift`** — pager selection (MANPAGER → PAGER → less → direct), terminal/interactive/subshell detection, `less -R` handling. Exposes a function that takes a string and either pipes through pager or writes to stdout.
4. No changes to existing model or pipeline code.
