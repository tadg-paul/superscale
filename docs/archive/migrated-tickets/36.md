## Original issue body

## Problem

`superscale --version` currently outputs just the bare version number:

```
1.0.1
```

This is the default ArgumentParser behaviour. It should identify the product and author for clarity, especially in bug reports, scripts, and logs.

## Expected behaviour

```
v1.0.1 Superscale by Taḋg Paul
```

Format: `v{major}.{minor}.{patch} Superscale by Taḋg Paul`

## Solution

Override the version string in `SuperscaleCommand.swift`. ArgumentParser's `CommandConfiguration.version` accepts an arbitrary string. Change it from `"1.0.1"` to `"v1.0.1 Superscale by Taḋg Paul"`, and update `scripts/release.sh` (or wherever the version is bumped) to maintain this format.

### Changes required

1. **`SuperscaleCommand.swift`** — Update `CommandConfiguration.version` to the new format.
2. **`scripts/release.sh`** (if applicable) — Ensure the version bump script writes the full format string, not just the number.

### What this does NOT change

- The version number itself
- Any programmatic version parsing (if scripts parse --version, they'll need to handle the new format)
