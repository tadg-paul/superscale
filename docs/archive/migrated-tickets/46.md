## Parent

Sub-issue of #14 (Phase 8: macOS SwiftUI GUI).

## Problem

Users working with multiple images need to queue and process them efficiently without manually dropping one at a time.

## Solution

1. Support dropping or adding multiple image files at once
2. Display a queue panel with thumbnail previews and filenames
3. Process items sequentially (configurable concurrency is a future enhancement)
4. Show per-item status and overall batch progress
5. Graceful error handling — a failed item does not block the rest
