## Original issue body

## Problem

The individual components (Image I/O, Tiler, CoreML inference) exist but are not wired together into a complete processing pipeline. The end-to-end flow — load image, split tiles, infer, stitch, write output — needs to be integrated with progress reporting and error handling.

## Solution

Implement a `Pipeline` coordinator in `Sources/Superscale/Pipeline/Pipeline.swift`:

1. Accept input path, output path, model name, scale, tile size
2. Load image via ImageLoader
3. Separate alpha channel if present
4. Split into tiles via Tiler
5. Run each tile through CoreMLInference
6. Report progress to stderr: "Processing tile N of M..."
7. Stitch upscaled tiles via Tiler
8. Upscale alpha via bicubic interpolation and recombine
9. Write output via ImageWriter
10. Return success/failure

### Error handling

- Invalid input path → descriptive error on stderr, exit code 1
- Unsupported format → list supported formats in error message
- Model not found → instructions to install or download
- CoreML failure → include MLModel error, suggest reducing `--tile-size`

### Progress reporting

- Output to stderr (not stdout) so piping works
- Format: `Processing tile 3 of 12...` (overwrite line for terminal, newline for non-TTY)
