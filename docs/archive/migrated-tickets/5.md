## Original issue body

## Problem

Superscale currently uses MIT as a placeholder licence. Before going public (Phase 5), the project licence must be finalised with full understanding of the obligations from bundled model weights.

## Context

- Real-ESRGAN model weights: **BSD-3-Clause** (Copyright 2021, Xintao Wang)
- GFPGAN weights: **not redistributed** (non-commercial components — see issue #1)
- BSD-3-Clause obligations: retain copyright notice, retain licence text, no endorsement
- BSD-3-Clause does not require downstream projects to adopt it

Downstream projects choose their own licences: Upscayl (AGPL-3.0), video2x (AGPL-3.0), ComfyUI (GPL-3.0), Cupscale (MIT). See [model licensing](https://github.com/tigger04/superscale/blob/master/docs/model-licensing.md) for detail.

## Solution

1. Review licence options (MIT, BSD-3-Clause, Apache-2.0) in light of model weight obligations
2. Decide on project licence — MIT is the current placeholder and the owner's default preference
3. Ensure `THIRD_PARTY_LICENSES` contains complete and accurate attribution for all bundled model weights
4. Confirm GFPGAN download approach (user downloads from upstream, we don't redistribute) does not create licence obligations
5. Update `LICENSE` file with the final choice
6. Update `docs/model-licensing.md` if anything changes

### Recommendation

MIT is compatible with BSD-3-Clause model weights. The only obligation is to include the BSD-3-Clause notice in `THIRD_PARTY_LICENSES`, which is already in place. MIT is the simplest choice and matches the owner's stated preference.
