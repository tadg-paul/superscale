## Original issue body

## Problem

When the user runs `superscale photo.png` and the required model is not installed, the CLI exits with a terse error:

```
Error: Model not found: realesrgan-x4plus. Run 'make convert-models' or download via --download-models.
```

This is unhelpful — the user doesn't know where to get the model or how to install it. For Homebrew installs the default model is bundled, but for source builds or when using a non-default model, there's no guided path to resolve the issue.

## Solution

When a model is not found:

1. **Interactive mode (TTY attached):** Prompt the user to download the missing model from the GitHub release:
   ```
   Model 'realesrgan-x4plus' is not installed.
   
   Download it now? (~67 MB) [Y/n]: 
   ```
   - If yes: download the `.mlpackage.zip` from the `models-v1` release, extract to `~/Library/Application Support/superscale/models/`, and continue with the upscale
   - If no: exit with error code 1
   - Show download progress (bytes/total, percentage)

2. **Non-interactive mode (no TTY):** Exit with error code 1 and a descriptive message, as currently. No prompting.

### TTY detection

Use `isatty(STDIN_FILENO)` to detect whether stdin is a terminal. This is the standard Unix approach and avoids prompting when piped or run from scripts.

### Download source

Model URLs and SHA256 hashes are already in `models/manifest.json`. Use `URLSession` for the download. Verify SHA256 after download.

### Storage location

Downloaded models go to `~/Library/Application Support/superscale/models/` (already in the search path via `ModelRegistry.userModelsDirectory`).
