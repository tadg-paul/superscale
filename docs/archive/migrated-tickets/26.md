## Original issue body

## Problem

The `-m`/`--model` help text says "Model name (auto-detected if omitted)" but doesn't tell users what valid model names are. Users have no way of knowing what to pass to `-m` without separately running `--list-models`.

## Solution

Update the `-m` option help text to reference `--list-models`:

```
Model name (auto-detected if omitted). Use --list-models to see options.
```
