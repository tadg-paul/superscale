## Original issue body

## Problem

Model descriptions (short summary and detailed text) are duplicated: once in \`HelpText.swift\` (CLI) and once in \`ModelPicker.swift\` (GUI). Adding or updating a model requires changes in multiple places.

## Solution

Add \`shortDescription\` and \`detailedDescription\` properties to \`ModelInfo\` in \`SuperscaleKit/ModelRegistry.swift\`. Both CLI help text and GUI model picker should read from this single source of truth.
