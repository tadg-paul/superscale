Transform the input image into a claymation still.
Preserve the main subject, pose, expression, composition, clothing, setting, and important object placement.
Recreate the image as a handmade stop-motion clay model scene, with plasticine texture, soft rounded forms, visible fingerprints, small surface imperfections, miniature set lighting, and slightly exaggerated but faithful shapes.
Keep the subject recognizable. Translate fine details into sculpted forms rather than photographic detail. The image should feel like a frame from a physical stop-motion production.
Avoid changing the subject’s identity, adding new characters, making the image too glossy, or turning it into a generic 3D render.
