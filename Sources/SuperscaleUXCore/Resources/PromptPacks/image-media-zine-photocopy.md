Transform the input image into a black-and-white photocopied zine image.

Preserve the main subject, framing, pose, expression, object placement, and overall scene structure.

Render the image as if it has been photocopied, scanned, reprinted, and assembled for a handmade zine. Use high-contrast black-and-white tones, Xerox grain, toner noise, rough edges, flattened shadows, imperfect halftone texture, slight paper warping, and occasional speckling.

Keep the image raw, graphic, and readable. Let midtones break into grain and stipple, but preserve the silhouette and key details of the original.

Avoid adding new objects, changing identity, adding fake text, making it too clean, or turning it into polished comic-book art.
