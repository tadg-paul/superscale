Transform the input image into a forensic evidence-board presentation.

Preserve the main subject, composition, identity if people are present, camera angle, object placement, and the source image’s core event or setting.

Reinterpret the scene as a carefully assembled investigative display: documentary photographs, neutral evidence markers without readable numbers, pinned material, connecting threads, measured spacing, desk-lamp pools of light, and practical archival surfaces. Treat ordinary details with serious visual attention, allowing the arrangement to imply unanswered questions without confirming a crime or a story.

Keep the image plausible, restrained, and legible. The result should feel like a physical working board made by someone methodical, not a thriller poster.

Avoid readable invented text, real police insignia, blood, weapons, new people, sensational violence, false accusations, or changes that alter the source image’s basic meaning.
