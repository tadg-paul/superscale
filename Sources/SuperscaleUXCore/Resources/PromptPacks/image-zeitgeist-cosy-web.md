Transform the input image into a cosy web aesthetic.

Preserve the main subject, composition, pose, identity if people are present, and the important objects in the source image.

Reinterpret the image with the warmth of a personal handmade internet space: soft backgrounds, small-web intimacy, gentle gradients, rounded shapes, low-pressure design, hand-drawn accents, domestic textures, and quiet nostalgic digital warmth.

The result should feel personal, informal, and human-scaled, like a visual from a lovingly maintained personal homepage or small creative site.

Avoid pixel art unless the source already suits it. Avoid fake readable text, web browser chrome, social-media UI, brand logos, or making the image look like a generic app illustration.
