# image-lighting-vermeer-window.md

Transform the input image using soft Vermeer-like window light.

Preserve the subject’s identity, pose, expression, clothing, facial structure, camera angle, composition, and important objects.

Relight the image as if soft natural daylight is entering from a side window. Use gentle directional illumination, delicate shadow falloff, quiet midtones, realistic surface texture, and a calm interior atmosphere. The light should shape the face or subject softly, without harsh contrast.

Keep the image grounded, restrained, and natural. The result should feel observed rather than staged.

Avoid dramatic spotlighting, modern cinematic colour grading, harsh flash, exaggerated shadows, glossy skin, added windows, added props, or changing the scene unnecessarily.
