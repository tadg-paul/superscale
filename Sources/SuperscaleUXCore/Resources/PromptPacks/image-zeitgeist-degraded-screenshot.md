Transform the input image into a degraded screenshot aesthetic.

Preserve the main subject, composition, pose, identity if people are present, object placement, and the overall structure of the source image.

Reinterpret the image as if it has been repeatedly screenshotted, reposted, compressed, cropped, and passed through multiple platforms. Use JPEG artefacts, mild blur, colour banding, crushed detail, softened edges, UI residue, uneven scaling, and social-media compression damage.

Keep the image readable and recognizable beneath the degradation. The effect should feel contemporary and app-native, not like VHS or analogue film.

Avoid adding readable captions, usernames, watermarks, fake UI text, new objects, or degrading the image so heavily that the subject is lost.
