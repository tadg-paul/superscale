Transform the input image into a VHS-era video screenshot.
Preserve the original subject, composition, framing, pose, expression, and object placement.
Reinterpret the image as if it were captured from an old videotape: soft resolution, analogue blur, colour bleed, interlacing, scanlines, tape noise, slight tracking distortion, crushed shadows, and muted highlights.
Keep the source image readable and recognizable beneath the degradation. The effect should feel like real video transfer damage, not a decorative overlay.
Avoid adding fake timestamps, subtitles, logos, new objects, or excessive glitching that obscures the main subject.
