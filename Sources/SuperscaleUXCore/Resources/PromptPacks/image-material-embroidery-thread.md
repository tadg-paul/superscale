Transform the input image into an embroidered textile artwork.
Preserve the main subject, pose, facial identity if present, composition, clothing structure, and important object placement.
Recreate the image using visible stitched thread on fabric. Use directional stitches, thread texture, raised embroidery, visible weave, slight puckering in the cloth, and simplified areas of colour built from stitch patterns.
Retain the recognizability and emotional tone of the original image while translating fine detail into thread direction, stitch density, and fabric texture.
Avoid changing facial features, adding new objects, inventing text, or making the result look like a printed image with a fabric texture overlaid.
