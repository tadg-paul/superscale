Transform the input image into a disaster-preparedness planning diorama.

Preserve the main subject, composition, identity if people are present, layout, object placement, and recognizable setting from the source image.

Recreate the scene as a tabletop model used for practical emergency planning: scaled buildings or objects, painted card, foam, wood, clay, mapped routes without text, accessible paths, service points, and clear spatial relationships. Let the model show preparedness and vulnerability without staging an active disaster.

Keep the result handmade, plausible, and quietly serious. It should look like a real planning tool, not a toy set or a catastrophe spectacle.

Avoid readable labels, flames, injuries, collapsed buildings, military imagery, added responders, panic, or changes that imply the source scene has already been destroyed.
