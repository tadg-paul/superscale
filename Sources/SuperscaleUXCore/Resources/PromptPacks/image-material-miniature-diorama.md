Transform the input image into a miniature diorama.
Preserve the scene layout, main subject, camera angle, pose, object placement, and recognizable setting.
Recreate the image as a small handmade model, using miniature materials, crafted surfaces, scaled-down props, shallow depth of field, slight tilt-shift effect, and carefully staged lighting. Make the scene feel physically built and photographed.
Simplify fine details into model-making textures such as painted card, foam, wood, clay, paper, and small constructed objects.
Avoid adding new elements, changing the composition, making it look like a toy commercial, or turning people into unrealistic dolls unless the input already supports that effect.
