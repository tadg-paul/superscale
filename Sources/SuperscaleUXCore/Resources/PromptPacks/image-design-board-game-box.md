Transform the input image into a painted board-game box illustration.

Preserve the main subject, composition, identity if people are present, central action, important objects, and the recognizable setting of the source image.

Reinterpret the scene as richly painted tabletop-game cover art: a strong central image, selective dramatic perspective, compact narrative clues, printed-cardboard texture, controlled colour, and a sense that the image contains rules and stakes without explaining them. Keep the source’s character visible beneath the designed presentation.

The result should feel like a real box from a clever, slightly unusual game, not a generic fantasy cover.

Avoid readable titles, logos, dice, playing pieces, rule text, exaggerated action poses, fantasy armour, extra characters, or a genre change unsupported by the source.
