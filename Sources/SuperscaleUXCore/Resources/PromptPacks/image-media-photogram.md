Transform the input image into a darkroom photogram.

Preserve the main subject’s silhouette, composition, object placement, identity where recognition can survive, and the key structural relationships in the source image.

Reinterpret the scene as if important forms had been placed directly on photographic paper: luminous silhouettes, translucent overlaps, deep blue-black shadows, chemical edge effects, paper grain, and light-bloom irregularities. Simplify detail into contact-based shapes while retaining the source image’s particular arrangement.

The result should feel handmade, physical, and surprising, with the logic of light rather than a digital negative.

Avoid readable text, photographic borders, added objects, decorative colour splashes, impossible anatomy, or abstraction so complete that no relation to the source remains.
