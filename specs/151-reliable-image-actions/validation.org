- *Procedure:* In the built Mac application, apply a FAL filter with scale off and save it with =Cmd+S=. Build a chain containing locks with and without cached upscales, press Save All once, and inspect the configured folder and result message. Save All responds to one click, performs no visible processing, writes one operator-ranked cached image or stored fallback per lock with no per-file dialogue, reports the result, and cancellation of destination access writes nothing.
